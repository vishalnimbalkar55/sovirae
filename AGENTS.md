# Instructions for coding agents

- **Do not push to GitHub.** Never run `git push`, create or push tags, or
  publish releases. Commit locally when asked; the owner pushes.
- Do not commit unless asked. Leave changes in the working tree and say
  what changed.
- Run the tests (`npm test`) and the type-check (`npx tsc --noEmit`) before
  reporting work as done.
- Record user-facing decisions and progress in the spec step files under
  `spec/steps/`.
